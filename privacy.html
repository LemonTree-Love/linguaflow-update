LinguaFlow 隐私政策 / Privacy Policy

最后更新 / Last updated: 2026-07-04(旧版 2026-04-23 的更新:补全词典代理兜底、GitHub Gist 同步、TTS 与词典服务清单、Chrome 内建 AI、新增权限说明)

核心承诺 / Summary

  • 没有开发者数据服务器。LinguaFlow 不收集、不上传、不出售任何个人数据;零遥测、零分析、零广告。No data collection, no telemetry, no analytics, no ads, no sale of data.
  • 所有学习数据仅存本地(chrome.storage.local):词库、复习记录、设置、API 密钥。All user data (vocabulary, review history, settings, API keys) stays in local browser storage.
  • 数据只在你主动使用某功能时,发往你自己选择/配置的服务,且仅为完成该次功能(单一用途)。Data leaves your device only when you actively use a feature, only to services you chose, only for that single purpose.

各功能的数据流向 / What goes where

功能发送内容接收方(由你选择/配置)
AI 翻译(点词/整句/批量预翻译整页与 YouTube 字幕/AI 故事/测验干扰项/字幕补标点)所查词语及其上下文句;批量模式为页面或字幕的文本片段与页面标题你配置的提供商:OpenAI、Anthropic、Google Gemini、DeepSeek、阿里云 DashScope、智谱、Groq、OpenRouter、DeepL、MyMemory、Google 翻译免费端点,或你自定义的兼容端点(API key 由你提供,仅存本地,直连不中转)
词典查询查询词Wiktionary、Free Dictionary、Cambridge、有道、Jisho、Tatoeba、Datamuse、Wikipedia
词典查询的代理兜底仅公共词典的查询词(绝不含 API key、词库或任何个人数据)当浏览器直连被 CORS 拦截时,经开发者的 Cloudflare Worker 或公共 CORS 代理(allorigins/codetabs/corsproxy/thingproxy)透传;不记录、不留存
语音朗读(可选云端声)朗读文本Azure、Google Cloud TTS、OpenAI、ElevenLabs(各需你自己的 key);默认系统本地语音不联网
Chrome 内建 AI(可选)——Gemini Nano 在你的设备本地运行,不联网
云同步(可选,默认关)词库与学习进度你自己的 GitHub Gist(用你的 token)或你配置的 WebDAV(如坚果云);开发者无任何中间服务器,亦无法访问

权限用途 / Permissions

  • host_permissions <all_urls> + scripting — 在你浏览的页面上取词、高亮、增强字幕;页面内容在本地处理,不上传。
  • storage / unlimitedStorage — 本地保存词库与设置(大词库不受 10MB 限制)。
  • activeTab / contextMenus — 右键翻译与页内工具。
  • alarms / notifications — 复习提醒与任务完成通知。
  • sidePanel — 浏览器侧栏学习面板。

数据最小化与变更披露 / Minimization & changes

每项数据的采集与发送均以完成对应功能所需为限;不用于任何其他目的。数据实践如有变更,将在本页面与扩展更新说明中先行披露后方才生效。Collection is limited to what each feature needs. Any change to these practices will be proactively disclosed here and in release notes before taking effect.
